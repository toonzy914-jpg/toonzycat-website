TOONZYCAT WEBSITE — DEPLOYMENT FILES

Contents:
- index.html: complete responsive static website
- assets/toonzycat-avatar.png: provided original mascot image
- assets/toonzycat-social-reference.png: provided design reference image (included for reference; not repeated on page)

Deploy to Vercel:
1. Upload these files to the root of your GitHub repository (toonzycat-website).
2. Open https://vercel.com/new and import the GitHub repository.
3. Framework preset: Other (or leave auto-detected); Build Command: leave empty; Output Directory: leave empty/default for a static root site.
4. Click Deploy.
5. Once deployed, open Project Settings > Domains to add toonzycat.com after registering the domain.

Notes:
- Social account links are based on the links provided in the conversation.
- This is a static site; no database or server is needed.
- The mascot image is used once in the header. The second reference image is included but not displayed.
